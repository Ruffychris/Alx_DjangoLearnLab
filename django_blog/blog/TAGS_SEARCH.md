# Tagging and Search

## Tags
- Add tags when creating/updating posts
- Displayed on post detail and list pages
- Click tag → filter posts with that tag

## Search
- Search bar in header
- Searches title, content, and tags
- Shows results on dedicated page
- URL: /search/?q=keyword

## Testing
1. Add a post with tags
2. Click a tag → see filtered posts
3. Use search → results show correct posts
