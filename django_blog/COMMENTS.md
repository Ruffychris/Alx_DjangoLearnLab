# Comment System

## Features
- Add comments to posts
- Edit own comments
- Delete own comments
- View all comments under posts

## URLs
/posts/<id>/comments/new/
/comments/<id>/update/
/comments/<id>/delete/

## Permissions
- Login required to comment
- Only authors can edit/delete
